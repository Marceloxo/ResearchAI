# 04_Literature_Index — Master Literature Index

## Purpose

The authoritative index of all papers in the ResearchAI literature system. Tracks every paper from intake through knowledge extraction.

## Contents

- `Literature_Index.md` — Master table of all papers
- `Literature_Intake_Template.md` — Template for new paper intake records

## AI Agent Usage

1. Before processing a new paper, check the index to avoid duplicates.
2. After each processing step, update the paper's status in the index.
3. Use the index for literature reviews and gap analysis.
4. When archiving old papers, update their status accordingly.
