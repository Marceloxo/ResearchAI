# 01_PDFs — Archived Original PDFs

## Purpose

Permanent archive of original PDF papers. This is the single source of truth for paper files.

## Input

- PDFs moved from `00_Inbox/` after classification.
- PDFs downloaded from academic databases.
- PDFs shared by collaborators.

## Output

- PDFs are consumed by MinerU Desktop for processing.
- The original PDF is retained here permanently.

## File Naming

- Use the Paper ID naming convention: `YYYY_FirstAuthor_ShortTitle.pdf`
- Example: `2023_Monteiro_DeepLearningSeismicSegmentation.pdf`

## AI Agent Usage

1. When processing a new paper, copy the PDF here with the correct Paper ID name.
2. Reference this file path when creating MinerU output.
3. Never delete a PDF from this directory — it is the archival layer.
4. If a PDF is corrupted or unreadable, note this in the Literature Index.
