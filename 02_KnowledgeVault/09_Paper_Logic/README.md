# 09_Paper_Logic — Paper Logical Structure Analysis

## Purpose

Analysis of how papers are logically constructed — their argument chains, methodology lineages, and contribution structures. This directory captures the *rhetorical and methodological architecture* of papers, going beyond what they say to understand *how* they build their argument.

## Contents

- Paper logic diagrams (text-based or Mermaid): introduction → gap → method → experiment → conclusion flow.
- Methodology lineage chains: which method builds on which prior method.
- Contribution decomposition: listing each contribution and how it is supported.
- Argument strength assessment: are the claims well-supported by experiments?
- Figure logic analysis: what does each figure prove, and is it convincing?

## Relationship to Other Directories

- References paper notes in `01_Papers/` for content.
- Traces method evolution through `03_Methods/`.
- Informs idea generation in `07_Ideas/` by revealing logical gaps.
- Guides writing strategy in `08_Writing/` by learning from strong paper structures.

## AI Agent Usage

1. When deeply analyzing a key paper, create a logic note that diagrams the argument flow.
2. Use methodology lineage chains to identify where new contributions could fit.
3. Compare argument structures across papers to learn effective writing patterns.
4. Flag unsupported claims or logical leaps that suggest research opportunities.
