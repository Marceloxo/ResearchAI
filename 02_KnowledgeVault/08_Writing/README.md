# 08_Writing — Writing-Related Notes

## Purpose

Notes, outlines, and drafts related to scientific writing. This is the planning and ideation layer for manuscripts — the bridge between knowledge and publication.

## Contents

- Manuscript outlines and structure plans.
- Key messages and contribution statements.
- Figure and table plans.
- Literature review outlines with paper links.
- Writing progress tracking.
- Rebuttal strategies and revision notes.

## Difference from `06_Writing/`

- `06_Writing/` (workspace level): Actual manuscript files — LaTeX source, figures, compiled PDFs.
- `08_Writing/` (vault level): Planning, outlining, and ideation — the intellectual scaffolding.

## Relationship to Other Directories

- Synthesizes knowledge from `01_Papers/`, `02_Topics/`, and `03_Methods/`.
- Reports results interpreted in `06_Experiments/`.
- Develops ideas from `07_Ideas/`.
- Outputs feed into `06_Writing/` (external to vault) as actual manuscripts.

## AI Agent Usage

1. When asked to outline a paper, create a writing note here that links to all relevant vault content.
2. Use contribution statements to clarify what is novel before drafting.
3. Track which experiments support which claims.
4. Generate literature review sections by aggregating topic and paper notes.
