Type: survey — 系统性综述深度学习在地震断层自动解释中的现状和未来方向

# One Sentence Summary / 一句话总结

全面综述了深度学习在地震断层解释中的应用，涵盖CNN、U-Net、Transformer、GAN等方法的分类体系，分析了数据集、评估指标和未来研究方向。

# Research Background / 研究背景

地震断层解释是地质结构分析的核心任务。深度学习技术在该领域快速发展，但缺少系统性的综述来梳理方法分类、数据集、评估标准和未来方向。

# Problem Definition / 问题定义

本文不提出新方法，而是系统回顾和分类现有深度学习断层解释方法，识别研究空白和未来方向。

# Main Contributions / 主要贡献

1. 系统分类深度学习断层解释方法（CNN/Transformer/GAN/半监督）
2. 汇总公开数据集和评估基准
3. 识别现有方法的局限性和未来研究方向

# Summary of Key Findings / 关键发现总结

1. CNN-based方法（U-Net变体）仍占据主导地位
2. Transformer方法开始出现但计算成本高
3. 合成数据训练到真实数据泛化仍是主要挑战
4. 缺乏统一的评估基准和标准化数据集
