# Research Problem / 研究问题

What are the fault structures and aftershock migration patterns of the unprecedented 2023 Kahramanmaraş Mw 7.9 & 7.8 doublet, and how do the Eastern Anatolian Fault (EAF) and Sürgü Fault (SF) differ in geometry and behavior?

# Main Contribution / 主要贡献

Built a catalog of 29,519 well-located events (Feb 1-28, 2023) significantly improving on routine INGV catalog. Revealed that EAF is near-vertical with shallow seismicity (<15 km) while SF has low dip angles (40°-80°), broad depth distribution to ~35 km, and shovel-shaped nucleation segment.

# Method Overview / 方法概述

1. **PALM workflow**: Sequential processing of continuous data through phase picking → association → location → matched filtering
2. **High-resolution catalog**: 29,519 well-located events in rupture region
3. **Fault imaging**: Aftershock spatial distribution used to delineate EAF and SF geometries
4. **Temporal analysis**: Examined foreshock activity and aftershock migration patterns

# Dataset and Evaluation / 数据集与评估

- **Mw 7.9 mainshock**: Feb 6, 2023, ruptured Eastern Anatolian Fault (EAF)
- **Mw 7.8 mainshock**: ~9 hours later, ruptured Sürgü Fault (SF)
- **Catalog**: 29,519 events (vs routine catalog which has far fewer)
- **Key findings**: EAF shallow seismicity (<15 km), SF broad depth (to ~35 km), no immediate foreshocks within ~5 days

# Why This Paper Matters / 为什么关注篇论文

Demonstrates the PALM workflow for large-scale aftershock cataloging — relevant for seismic monitoring systems. The Mw 7.9 & 7.8 doublet is an exceptional natural laboratory for studying multi-fault rupture and aftershock dynamics.

# Limitations / 局限性

- Early aftershock catalog only (Feb 2023) — longer-term evolution not covered
- PALM workflow details not fully specified
- No quantitative comparison of PALM vs other picker methods
- Dense network only available for this specific sequence
