# 01_Papers — Paper Reading Notes

## Purpose

Structured reading notes for research papers. Each note captures the key contributions, methods, results, and personal critique of a single paper.

## Contents

- Paper notes following the `Paper_Note_Template` from `Templates/`.
- Each note links to the original PDF in `01_Literature/PDFs/`.
- Each note links to the MinerU Markdown version in `01_Literature/Markdown/`.
- Cross-links to relevant methods, tasks, datasets, and topics within the vault.

## Relationship to Other Directories

- Links to source materials in `01_Literature/` (external to vault).
- Feeds concept definitions into `03_Methods/` and `04_Tasks/`.
- Supports gap analysis in `07_Ideas/`.
- Contributes to paper logic chains in `09_Paper_Logic/`.
- Summarized in `02_Topics/` MOC pages.

## AI Agent Usage

1. When asked to analyze a paper, create a new note here using the paper template.
2. Cross-link the note to existing methods, tasks, and datasets that the paper references.
3. Tag the note with relevant topic and method tags.
4. Update related MOC files in `00_Meta/` if the paper opens a new sub-topic.
5. If the paper introduces a novel method, also create an entry in `03_Methods/`.
