## Experiment Lifecycle / 实验生命周期

```
Idea → Hypothesis → Experiment Design → Execution → Analysis → Conclusion
  ↑                                                                    │
  └────────────────── New Idea ←───────────────────────────────────────┘
```

Every experiment, even a failed one, should produce:
1. An interpretation note in `06_Experiments/`
2. A "what to try next" section that feeds into `07_Ideas/`

---

## How to Use / 使用方式

1. After running an experiment, create an interpretation note in `06_Experiments/`.
2. Add its `[[wikilink]]` to the appropriate section above.
3. Always link the experiment to its method, dataset, task, and originating idea.
4. Extract lessons learned and add them to the section above.
