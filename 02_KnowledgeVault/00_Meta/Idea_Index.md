## Idea Lifecycle / 想法生命周期

```
Gap Identified (from Paper/Method/Task)
    ↓
Idea Note Created (Idea_Template)
    ↓
Prioritized (feasibility, impact, novelty)
    ↓
Experiment Planned (Experiment_Template)
    ↓
Experiment Executed → Results
    ↓
Validated → Promoted to Project (03_Projects/)
    or
Invalidated → Archived with lessons learned
```

---

## How to Use / 使用方式

1. When you identify a research gap, create an idea note in `07_Ideas/`.
2. Add its `[[wikilink]]` to the appropriate section above.
3. Link the idea to the paper/method/task that inspired it.
4. When an idea matures into a project, move it to "Active Ideas" and link to the project.
