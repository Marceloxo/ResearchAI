## Writing Workflow / 写作流程

```
Knowledge Accumulation (Papers, Methods, Experiments)
    ↓
Research Story Formulation (Writing_Template)
    ↓
Outline Development
    ↓
Draft Writing (06_Writing/ in workspace)
    ↓
Revision
    ↓
Submission
```

---

## How to Use / 使用方式

1. When starting a new paper, create a writing plan in `08_Writing/` using `Writing_Template`.
2. Link the plan to all relevant knowledge: papers, methods, experiments, ideas.
3. When analyzing a well-written paper, create a logic note in `09_Paper_Logic/`.
4. Extract writing lessons and apply them to your own manuscripts.
