# 00_Inbox

## Purpose

Temporary input area for new materials before they are processed and sorted into permanent locations.

## What Goes Here

- Newly downloaded papers (PDFs) awaiting review
- Temporary notes and scratch files
- Unclassified or unprocessed files
- Draft materials that have not yet found a home

## Workflow

```
Inbox → Processing → Permanent Storage
```

Items should not remain in the Inbox indefinitely. Once processed, they should move to the appropriate directory:

- Papers → `01_Literature/`
- Notes → `02_KnowledgeVault/`
- Code → `03_Projects/` or `04_Tools/`
- Writing → `06_Writing/`
- Ideas → `07_Research_Ideas/`

## Relationship to Other Directories

The Inbox is the entry point. It feeds into every other directory. It should be reviewed regularly to prevent accumulation.
